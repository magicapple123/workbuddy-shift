## v0.2.1-rc.1（预发布）

这一版是第三轮整改的验收版本，覆盖更新、发布、统计、存储与客户端支持。

### 更新与发布
- 更新检查支持系统代理与设置页代理；20 秒内必有结果，并发点击只跑一次。
- 签名失败、缺平台、网络失败分开提示；签名失败时提供「打开 Releases 手动下载」。
- 发布改为 draft 全部上传后原子转正；更新清单固定到 tag 路径，补全安装包签名与发行说明。

### 统计与存储
- 官方用量不可用时显示横幅与覆盖区间；近 7 天/本月覆盖不足显示「—」，不再用今日值顶替。
- Token 统计支持按账号筛选，新增 Excel 导出（CSV 同时修复表头与数值格式）。
- 存储页改为一次扫描出全部口径：2 万文件合成树上「一屏」从 1810 ms 降到 746 ms。
- 存储「定位」支持任意工作目录（只读白名单外的路径会被拒绝并给出原因）。

### 客户端
- 新增 JetBrains 会话客户端；切换失败可诊断，关闭超时会重开已关闭的 IDE，多目标写入失败会逆序回滚。
- 权限检测按钮按平台渲染，macOS 才显示「完全磁盘访问」，其余平台给对应引导。
- 账号卡多端水印改为扇形错位；悬浮窗设置窗支持深色（全量 token 化）。

### 已知限制
- VS Code 插件的限额数据暂不支持（日志结构不同），界面会明确标注。
- Linux arm64 仅提供 CLI / WebUI，不产出桌面安装包。
