# WorkBuddy Shift 0.3.0（预览版 rc.1）

发布日期：2026-11-22

这是 0.3.0 的预览版，用于把这一批改动先交给愿意试的人。正式版会在收集反馈后再发；预览版与正式版的数据格式一致，升级不需要迁移。

## 新功能

### 账号资产：加密备份

- **加密导出/导入**：账号页 →「添加与迁移」→ 加密导出，设置口令后生成 `workbuddy-shift-accounts-YYYY-MM-DD-encrypted.json`。
- **口令规则**：至少 8 位，由内核统一校验（绕过界面直接调接口也一样拒）。
- **错口令不写盘**：解密失败时账号库**逐字节不变**，不会出现「导入失败但账号被改了一半」。
- **算法**：PBKDF2-SHA256（600k 迭代）+ AES-256-GCM，信封自带参数，日后提高强度仍能解旧文件。

### 会话搬运

- **置顶跨账号同步**（#205）：复制已置顶的会话，目标账号的置顶列表与顺序一并同步；目标已有的置顶不受影响。
- **工作记忆可选同步**（#209）：复制时可勾选同步 `MEMORY.md`，默认关闭；目标已有内容只追加缺失行，不静默覆盖。
- **复制保留创建时间**（#204）：复制后的会话不再把创建时间重置为切号时刻，历史排序与统计不再被压平。
- **CodeBuddy IDE 支持新增关联会话**（#195）：此前该客户端下按钮恒为禁用；现在可复制并建立关联。**需先完全退出 CodeBuddy IDE**。

### 国际版每日活跃（#214）

- **手动一键打卡**：账号页 →「每日活跃」，二次确认后逐个账号执行，结果分「成功 / 今日已完成 / 不支持 / 失败」。
- **零自动触发**：没有定时器、不在启动或切号链路上调用，只在你点的时候跑一次。
- **当天去重**：已完成直接跳过，不发任何请求。

### 其它改进

- **最近使用与多维排序**（#184）：卡片显示「最近切换」；排序支持 9 个维度（积分紧迫、最后使用、剩余积分、添加时间、名称等），选择会记住。
- **限额来源补齐**（#188、#120）：VS Code 插件宿主的 429 日志纳入扫描；同一次限流只显示一个标记；拉取失败不再清空已有台账。
- **签到分散执行**（#199）：未设置时间段时，签到自动分散在默认窗口内，不再「启动瞬间把 N 个号全签完」。

## 修复

- **切号可能把旧令牌写回**（#202）：刷新与切号之间加了跨进程写入锁，并在写回前比对令牌新鲜度；磁盘已更新则放弃写回并提示重切，不再随机掉登录。
- **导出推进刷新时钟**（#203）：导出保留真实 `refreshedAt` / `expiresAt`，重复导出不再让「几小时前刷新过」看起来像刚刷新。
- **Windows 关闭强杀编辑器**（#119、#29）：改为先发关闭请求并等待，超时才强杀；写 `state.vscdb` 前做行级快照，写完解密回读比对，不一致自动还原；启动后校验进程存活，秒退不再谎报「已重新打开」。
- **401 给用户看整段网页**（#189）：统一在请求收口处分类为「登录已失效 / 网关拦截 / 官方错误 / 格式异常」四档人话，不再回显 HTML。

## 行为变化（升级前请知悉）

- **错误文案变了**：401、网关错误不再显示原始网页；如果你的脚本靠匹配旧文案做判断，需要改成读 `failureKind` 或状态码。
- **2xx 但返回网页**：现在按失败处理（此前被当成空结果），避免把「网关登录页」读成「签到状态正常」。
- **加密备份文件**：这是新格式，旧版本打不开；明文 JSON 导入仍然支持。

## 已知限制与未验证项

这两项功能是本版新增，但**没有在真实环境完成端到端验证**，请在遇到问题时带上日志反馈：

- **每日活跃（#214）**：只做了手动入口，报文按上游实现移植并修了四处已知缺陷（SSE 泄漏、错误当成功、缺重试、模型未生效仍上报）。首次使用请先用一个小号试；失败时会清理测试会话，但如果你看到网页端遗留了会话，请把账号和时间点发给我们。
- **CodeBuddy IDE 关联会话（#195）**：需要先完全退出 IDE；复制后仍要手动勾选会话。IDE 运行中被检测到时会直接提示退出，不会替你关闭进程。

其它限制：

- 关联同步判定为 `unknown`（无法确认两份内容先后）时，系统**不会覆盖**任何一份；此时会提示原因并给出「重新复制并重建关联」入口，而不是静默失败。
- 加密备份依赖系统凭据能力（Windows DPAPI / macOS 钥匙串 / Linux Secret Service），无桌面环境的 Linux 上不可用。

## 下载哪个？

| 你的系统 | 下载这个 | 说明 |
| --- | --- | --- |
| Windows 10 / 11（x64） | `workbuddy-shift_0.3.0-rc.1_x64-setup.exe` | 安装包未做代码签名，SmartScreen 会拦一次：点「更多信息」→「仍要运行」 |
| macOS（Apple 芯片，M 系列） | `workbuddy-shift_0.3.0-rc.1_aarch64.dmg` | 首次打开若提示「无法验证开发者」，Control + 点击应用 →「打开」 |
| macOS（Intel） | `workbuddy-shift_0.3.0-rc.1_x86_64.dmg` | 同上 |
| Linux（通用） | `workbuddy-shift-linux-x86_64.AppImage` | 下载后 `chmod +x` 再运行 |
| Debian / Ubuntu | `workbuddy-shift-linux-x86_64.deb` | `sudo dpkg -i` 安装 |
| 不想装桌面版 | `npm i -g workbuddy-shift` | 需要 Node.js 20.19+，浏览器访问 WebUI |
| 服务器 / NAS | `docker pull ghcr.io/magicapple123/workbuddy-shift:0.3.0-rc.1` | 默认只绑 `127.0.0.1`，局域网访问要显式放开 |

**分不清 Mac 是哪种芯片**：左上角  →「关于本机」，看「芯片」一行——Apple M 系列选 `aarch64`，Intel 选 `x86_64`。

**这是预览版**：建议先在一份备份或非主力账号库上试。升级前可以用「加密导出」留一份（这也是本版新增的能力）。

## 升级说明

- 桌面版与 npm 版可在应用内直接升级；数据目录、默认监听与 Host/Origin 校验口径不变。
- 预览版会显示为 `Prerelease`，不会被自动更新强推；想留在 0.2.6 的用户不受影响。
