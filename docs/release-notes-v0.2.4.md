# WorkBuddy Shift 0.2.4

发布日期：2026-11-21

本次更新集中在三件事：会话复制搬得完整、账号切换前后状态不丢、以及一批日常使用中的细节修正。

## 新功能

- **账号标记**：给账号加一条自定义标记（文本 + 颜色 + 到期时间），卡片状态区显示标记图标，悬停可看到内容与剩余时间，点开可编辑或手动解除。标记会随账号一起导出导入，刷新 Token、扫码重登都不会丢。账号列表的排序也新增了「标记」一项，按标记时间排，没有标记的账号始终排在最后。
- **JetBrains 全家桶**：支持范围从 IDEA / PyCharm 扩展到 16 个产品——IDEA、PyCharm、WebStorm、GoLand、CLion、PhpStorm、Rider、RustRover、RubyMine、DataSpell、DataGrip、Aqua、MPS、Writerside、Android Studio，以及已停止更新的 AppCode（会在界面上标注停更）。Android Studio 的配置目录在 `Google` 下而非 `JetBrains` 下，两种目录结构已分别处理。
- **悬浮栏新增 DSH 来源**：除 WorkBuddy / Codeg / Codex 之外，现在也能看到 DSH 的会话状态。该项为只读，不会改写 DSH 的任何文件。
- **命令行 JSON 输出**：新增 `accounts` / `limits` / `credits` / `status` / `inspect` / `switch` 的 JSON 形式，便于脚本和 AI 调用。输出为单行 JSON 并带版本号字段，进度信息走标准错误，因此可以直接管道给其他程序。退出码区分成功、未找到、参数错误、存在活跃会话被拒绝、致命错误五种情况。输出不含任何令牌，只读命令不会修改任何状态。
- **后台发现新版本时发系统通知**：窗口不在前台时也能收到提醒，同一版本只提醒一次。

## 修复

- **复制后「共消耗」变少**：此前复制只搬聊天正文，没有搬用量账本，目标账号会显示 0 或明显偏少。现在用量与中断记录会随会话一起搬运，数值与源账号一致。若目标数据是旧版本、缺少对应表，会在复制结果里说明，而不是静默丢数据；万一账本写入失败，会给出「仍然复制（不带用量与中断记录）」的选择，由你决定要不要先拿到正文。
- **换号后会话落在错误的分组**：此前按分组名匹配，两个账号里同名但不同目录的分组会串。现在按目录路径匹配，路径相同才复用；同名只作为兜底。同时补上了分组与目录的绑定关系，修复了「在迁移分组里新建任务后，迁移过来的会话消失」的问题。
- **切号让定时任务静默失效**：切换到新账号后，原账号启用的定时任务会继续按计划触发但实际不会执行。现在切号前会提示有几个启用的任务（默认只提示、不改动），可在设置里开启「随切号复制定时任务」。开启后只复制简单任务，源任务会被暂停而不是删除；含技能、连接器或工作区引用的任务只提示不复制，避免复制出一个跑不通的任务。
- **网络波动被误判为「需重新登录」**：断网、代理故障、网关错误页、限流、服务端 5xx 此前都会把账号标成需要重新登录，实际网络恢复后账号是好的。现在只有明确失效（凭据被吊销）才会标记，其余按临时失败处理并自动重试；一旦续期成功，标记会自动清除。
- **更新提示卡片撑出窗口**：更新说明较长时卡片会超出窗口、按钮被挤出屏幕。现在说明区有高度上限并单独滚动，标题、关闭按钮和操作按钮始终可见。
- **悬浮栏把自动批准误报成「待确认」**：工具授权被自动通过的瞬间也会显示一张卡片，看起来像幽灵提示。现在这类瞬时状态不再显示；真正需要你处理的授权会以「需要授权」单独标出，并可一键跳到对应会话。
- **积分统计切换账号后跳回第一个标签页**：现在会停留在你正在看的那一页。

## 优化

- **更新说明改为摘要**：更新卡片只显示精简后的说明，底部可打开完整发布页面。老版本客户端收到的长文本也会在显示前自动精简。
- **切号预览更快**：会话没有变化时，重复打开预览不再重新读取全部会话文件，第二次打开明显更快。
- **设置页的同步表格默认收起**：账号清单与待同步表默认折叠，标题行仍显示「账号数 / 可同步 / 未登录」等摘要，需要时再展开。
- **紧凑模式的状态不被挤掉**：卡片状态区固定显示三个位置，其余折叠为「+N」，标记永远排在最前；产品切换从一排按钮收成一个下拉，窄窗口下名称也保持可读。
- **账号信息弹窗的「卡片显示」简化**：原来有「昵称 / 备注 / 手机号」三个选项，其中「备注」与新的取名规则重复，现在收成「账号名 / 手机号」两项；此前选过「备注」的账号会自动按新规则显示，不需要重新设置。
- **账号显示名四处统一**：账号卡、Token 统计、积分统计、签到日志此前各用一套取名规则，同一个账号在不同位置可能显示不同名字。现在统一为「手机号（若显式设置）→ 备注 → 昵称 → 邮箱 → UID」。
- **悬浮栏的高亮提醒**：窗口不在前台时，如果出现新的待处理事项，侧栏会高亮闪一下（2.4 秒自动消失），不会一直闪到你烦。
- **复制前提示专家的可用性**：如果目标账号没有该会话使用的专家，预览里会标出并汇总条数，但默认仍会复制，不影响其他内容。

## 行为变化

- **「需重新登录」只在真正失效时出现**：网络问题不再让账号变红。代价是：真正失效的账号最迟约 60 秒后才会出现提示（此前是立刻），因为要先做一次复核确认。
- **更新说明不再全文展示**：卡片只显示摘要，完整内容通过底部入口打开。
- **旧系统提示**：在界面组件过旧的系统上（如 macOS 13.3 以下且未更新 Safari），应用会明确提示版本过低并给出升级路径，而不是显示一个错乱的界面。

## 升级说明

- 0.2.1 / 0.2.2 / 0.2.3 用户可直接在应用内升级。
- 升级后首次切号会看到定时任务提示（如果原账号有启用的任务），这属于预期行为，可在设置里关闭。
- 若你在旧版本里已经看到某个账号被标为「需重新登录」，升级后只要该账号实际可用，标记会在下一次续期成功后自动消失，无需手动处理。
