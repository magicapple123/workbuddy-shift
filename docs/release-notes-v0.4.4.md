# WorkBuddy Shift 0.4.4

发布日期：2026-11-26

只调整积分展示，不加功能。账号、备份、关联与会话数据格式都没有变化，0.4.3 可以直接升级。

## 改了什么

**积分明细不再列出「已用完」的资源包**

「积分」页的明细此前会把已用完、但还没到期的资源包也列出来（显示成 `0 / 100`、`已用 100`）。包越多、用得越久，这类噪音行越多，也不利于判断「现在还能用多少」。0.4.4 起：

- 明细只展示「剩余 > 0」的资源包；
- 所有资源包都用完时，显示「当前没有可用积分，已用完的资源包不展示。」，而不是一片 0；
- 与账号卡「近期到期」的口径对齐——账号卡本来就不列已用完的包，现在两处的数量能对上。

**积分条恢复绿 / 橙 / 红**

0.3.x 起主色改成蓝色，积分条也跟着变蓝，临期与过期只能靠深浅区分。0.4.4 起恢复按状态着色：

- 正常：绿；
- 7 天内到期：橙；
- 已过期：红（深色模式用更亮的红）。

账号卡行内、全部积分包弹窗、积分明细页、模型用量与账号占比条现在用同一套三态；此前「已过期」在账号卡行内是橙色、在明细页仍是满格绿条，这次一并修正。

## 升级后要做什么

不需要手动操作，0.4.3 可直接升级。

## 已知限制

- 已用完资源包的「已用 X」不再出现在积分明细里（账号卡同样不展示）。这是为了让明细只回答「现在还能用多少」的有意取舍。
- 剩余不足 0.01 的极小残余会因两位小数显示成 `0`，仍会保留一行；如果更希望这类残余也隐藏，欢迎反馈。
