# WorkBuddy Shift 0.2.3

发布日期：2026-11-20

本次更新继续修复会话复制被文件损坏卡住的问题，覆盖了一种新的损坏形态，并让失败提示指向真正的阻断位置。

## 修复

- **行首空填充导致复制失败**：部分会话文件在异常退出后，某一行的开头会被写入一段空字节（NUL）填充，后面才是完整记录。此前复制会报「第 N 行的格式无法识别」并停止。现在会剥离这段空填充，保留其后的完整记录，复制正常完成；填充本身不含任何会话内容。
- **整行的空填充**：如果某一行全部是填充、没有任何记录，会连同换行一起移除，不影响前后记录。
- **失败提示指向真正的坏行**：当文件里同时存在「可修复的坏行」和「无法修复的坏行」时，此前提示可能只指向可修复的那一行。现在两处都会报出来，可以直接定位真正的阻断点。
- **失败提示重复**：修复了同一句诊断在提示里出现两遍的问题。

## 优化

- 复制结果会说明剥离了多少字节的空填充，以及是否还有记录被跳过。
- 源文件仍然只读，所有处理只作用于复制出的副本。

## 升级说明

- 0.2.1 / 0.2.2 用户可直接在应用内升级。
- 若提示「签名校验失败」，请手动下载本版本安装一次，之后即可恢复自动更新。

## 其余文件是什么？

| 文件 | 用途 |
| --- | --- |
| *.sig | 自动更新的签名文件，不要手动下载 |
| latest*.json | 客户端检查更新用的清单，不要手动下载 |
| workbuddy-shift-macos-*.app.tar.gz | macOS 自动更新包，供应用内升级，无需手动安装 |

> `latest-macos-*.json` 与 `latest-darwin-*.json` 内容相同：前者是生成器侧的可读名，
> 后者是 Tauri 在 macOS 上实际请求的名字，两者都必须保留。
