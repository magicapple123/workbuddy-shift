# WorkBuddy Shift v0.2.1

第三、四轮整改合并后的正式版：自动更新、多客户端统计、积分账本与设置同步。

## 主要变化（第四轮）

- **账号管理**：新增六项排序（额度恢复时间 / 积分到期 / 剩余积分 / 最近更新 / 名称 / 默认），
  同一项再点一次反转；无值账号始终排在最后。
- **Token 统计**：按 6 个来源拆分（WorkBuddy、WorkBuddy 国际版、CodeBuddy CLI、VS Code 插件、
  JetBrains 插件、CodeBuddy IDE），`WorkBuddy/` 空壳目录不再重复计数。
- **积分统计**：新增「全部」范围与本地 SQLite 账本（默认 30 天；90 天窗口不可用时回退并说明）；
  四卡、趋势、账号构成同口径；新增按客户端筛选，选中具体客户端时标注「据明细汇总」与条数。
- **导出**：Token 与积分统一为「导出 ▾」菜单；积分新增 Excel（多 sheet，每个 sheet 末行写口径说明）。
- **存储**：Windows 上「工作目录」正确打开目标目录，不再跳到「文档」；跨系统路径给出可读提示。
- **JetBrains**：按项目（projectKey）读取与复制会话，不再漏掉项目桶；当前账号直接读插件登录态，
  无需手动点「检测账号」。
- **设置同步**：自动同步也写「最近一次」记录；纯 revision / 归属差异不再计为变更；
  同步前二次确认（账号数、主题覆盖、备份目录）；新增备份列表与还原；文案改为「N 个工作区配置」。
- **限额**：VS Code 日志探针只采样、不判定；跨客户端兜底显示真实来源（WorkBuddy / CLI / IDE），
  不再笼统写「其它客户端」；紧凑卡片修复长文案挤掉账号名的问题。
- **更新**：启动发现新版本时右下角弹卡片（说明 + 稍后 + 完整说明）；设置页新增「启动时检查更新」；
  代理按钮只在改动后出现，支持回车保存，检查前自动保存。

## 主要变化（第三轮，随本版发布）

- **自动更新**：启用系统代理；检查与下载共用同一代理配置，只填不保存也能下载；
  检查 20 秒内返回结果；签名失败时引导手动下载一次。
- **更新发布**：Release 先以 draft 上传全部资产，成功后一次性切到 latest；
  清单中的资产 URL 固定到 tag，避免「检查到旧版、下载到新版」。
- **JetBrains**：新增关联会话与账号切换支持；有未识别的运行中 IDE 时拒绝写入并提示先退出。
- **统计**：Token 统计支持按账号筛选；积分官方用量失败时回退本地观察值并标注来源；
  Token 导出新增 xlsx，CSV 不再出现空列错位。
- **存储**：打开页面即预热总览，扫描更快；「工作目录」可以正确定位。
- **界面**：悬浮窗全界面深色适配；权限检测按钮在 Windows 可用；
  跨账号同步表格、账号卡水印与自动签到文案修正。

## 其余文件是什么？

| 文件 | 用途 |
| --- | --- |
| *.sig | 自动更新的签名文件，不要手动下载 |
| latest*.json | 客户端检查更新用的清单，不要手动下载 |
| workbuddy-shift-macos-*.app.tar.gz | macOS 自动更新包，供应用内升级，无需手动安装 |

> `latest-macos-*.json` 与 `latest-darwin-*.json` 内容相同：前者是生成器侧的可读名，
> 后者是 Tauri 在 macOS 上实际请求的名字，两者都必须保留。

## 升级说明

- 从 0.2.0 起使用同一签名密钥；0.2.0 与 0.2.1-rc.1 用户可直接在应用内升级到本版。
- 若提示「签名校验失败」，说明当前安装版本的可信公钥与新包不一致，
  请手动下载本版本安装一次，之后即可恢复自动更新。
