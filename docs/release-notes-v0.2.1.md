# WorkBuddy Shift 0.2.1

发布日期：2026-11-19

本次更新让多客户端用量统计更准确、积分记录可追溯，并改进了账号管理、设置同步与自动更新的日常体验。

## 新增

- **账号排序**：支持按额度恢复时间、积分到期时间、剩余积分、最近更新和名称排序；再次点击同一项可反向排序。
- **用量来源拆分**：Token 统计按 WorkBuddy、WorkBuddy 国际版、CodeBuddy CLI、VS Code 插件、JetBrains 插件和 CodeBuddy IDE 分别统计，不再重复计算。
- **积分范围与账本**：新增「全部」范围，本地记录每日请求明细；90 天窗口不可用时自动回退到 30 天，并在页面上说明原因。
- **按客户端查看积分**：可按客户端筛选，查看该客户端的今日、近 7 天和本月用量，以及对应的请求条数。
- **统一导出菜单**：Token 与积分统计都改为「导出」菜单；积分新增 Excel 格式，按主题分表，并在每张表末尾附口径说明。
- **启动更新提示**：检测到新版本时在右下角显示更新卡片，可直接查看更新说明，或选择稍后处理。
- **启动时检查更新**：可在设置中开启或关闭。

## 优化

- **账号卡片**：重新排布状态标签与工具入口，窗口较窄时不再挤占账号名称。
- **限额提示**：跨客户端限流会标注实际来源（WorkBuddy、CodeBuddy CLI 或 IDE），并说明可能受影响的范围。
- **设置同步**：同步前展示影响范围并要求确认；支持查看和还原历史备份；仅版本号不同不再计为待同步变更。
- **JetBrains**：按项目识别会话，复制时保留项目归属；当前登录账号读取更准确，无需手动检测。
- **存储管理**：Windows 下「工作目录」可直接打开目标文件夹。
- **自动更新**：检查与下载共用代理设置，检查超时时间缩短；签名校验失败时给出明确的手动下载指引。
- **界面**：悬浮窗适配深色模式，权限检测在 Windows 上可用。

## 修复

- 修复 Windows 下「工作目录」错误打开「文档」的问题。
- 修复 Token 统计重复计算 WorkBuddy 用量的问题。
- 修复积分总计只显示最近 30 天、无法查看更早记录的问题。
- 修复同步预览把纯版本号差异误判为待同步变更的问题。
- 修复账号卡状态标签过多时账号名称被挤掉的问题。
- 修复部分文案错误与导出空列错位的问题。

## 升级说明

- 0.2.0 与 0.2.1-rc.1 用户可直接在应用内升级。
- 若提示「签名校验失败」，请手动下载本版本安装一次，之后即可恢复自动更新。

## 其余文件是什么？

| 文件 | 用途 |
| --- | --- |
| *.sig | 自动更新的签名文件，不要手动下载 |
| latest*.json | 客户端检查更新用的清单，不要手动下载 |
| workbuddy-shift-macos-*.app.tar.gz | macOS 自动更新包，供应用内升级，无需手动安装 |

> `latest-macos-*.json` 与 `latest-darwin-*.json` 内容相同：前者是生成器侧的可读名，
> 后者是 Tauri 在 macOS 上实际请求的名字，两者都必须保留。
