# WorkBuddy Shift 0.2.2

发布日期：2026-11-20

本次更新修复了部分会话无法复制的问题，并让复制前的检查结果更容易理解。

## 修复

- **会话复制被整份拒绝**：当源会话文件的最后一行在写入时被中断（客户端崩溃、强退或异常关机），复制会报「第 N 行的格式无法识别，内容可能不完整」并完全无法进行。现在会跳过这半条没有写完的记录，同一行里已经写完的内容以及它前面的会话记录都会保留，复制正常完成。
- **两行粘连导致复制失败**：上次退出时没有写入换行，两条会话记录挤在同一行时，复制同样会被拒绝。现在会按记录边界无损拆开，内容不丢失。
- **其它损坏仍然明确拒绝**：只有真正写到一半的记录才会被跳过；末尾多逗号、单引号、非法数值等「写完但不合法」的损坏不会被猜测修补，仍会报错并指出具体位置。

## 优化

- **报错更具体**：会话内容校验失败时，提示会带上出错列号、错误类型、该行字节数，以及是否为文件最后一行，便于判断是写入中断还是文件损坏。
- **复制结果有说明**：复制时如果对源会话做过上述处理，结果提示会说明跳过了什么、保留了什么。
- **源文件不会被修改**：所有处理只作用于复制出的副本，原会话文件保持原样。

## 升级说明

- 0.2.1 用户可直接在应用内升级。
- 若提示「签名校验失败」，请手动下载本版本安装一次，之后即可恢复自动更新。

## 其余文件是什么？

| 文件 | 用途 |
| --- | --- |
| *.sig | 自动更新的签名文件，不要手动下载 |
| latest*.json | 客户端检查更新用的清单，不要手动下载 |
| workbuddy-shift-macos-*.app.tar.gz | macOS 自动更新包，供应用内升级，无需手动安装 |

> `latest-macos-*.json` 与 `latest-darwin-*.json` 内容相同：前者是生成器侧的可读名，
> 后者是 Tauri 在 macOS 上实际请求的名字，两者都必须保留。
