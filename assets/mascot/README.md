# 吉祥物资源（WorkBuddy Shift）

两套素材，同一只猫，用途不同。原图保存在 `source/`，不要直接改。

| 文件 | 说明 | 用在哪 |
|---|---|---|
| `mascot-color.png` | 彩色版，1024×1024，透明底 | 母版，按需导出其它尺寸 |
| `mascot-color-512/256/128.png` | 同上，常用尺寸 | `-128` 用在侧边栏底部的角色头像 |
| `mascot-mask.png` | 纯黑剪影，眼睛为镂空，透明底 | 侧边栏标题标记（`product-marks.tsx`）；托盘图标的生成源 |
| `source/mascot-color.jpg` | 原始彩色图（白底，未处理） | 换色、重制时的母版 |
| `source/mascot-mask.png` | 原始剪影图（白底） | 同上 |

## 使用约定

- **浅色背景**用 `mascot-color.png`：白色描边环自带浅蓝轮廓，不会被背景吃掉。
- **深色背景**优先用 `mascot-mask.png` 染色（`filter: invert()` 或 CSS mask），比彩色版更协调。
- 彩色版的眼睛是白色实心，剪影版的眼睛是镂空——两者不可互换使用。
- 最小使用尺寸建议 64px；低于 48px 时细节会糊，改用剪影版。

## 生成方式（可复现）

1. 彩色图与剪影图的包围盒对齐（误差 1–2px），因此剪影可作为彩色版的 alpha 遮罩。
2. 用剪影亮度反相作为 alpha，再对被包围的透明区（眼睛）做孔洞填充，恢复白色眼珠。
3. 输出 PNG 并批量缩放。

脚本：生成用的是一次性本地 Node 脚本（依赖 `sharp`），未随仓库发布——它把两张原图按固定
路径读入后写出上述 PNG。仓库里的 PNG 就是最终产物；要重做，按上面三步写一个等价的脚本即可，
`source/` 下的原图是唯一需要的输入。
